# こだわりをたどる｜Craft Discovery

工芸以外を専門とするデザイン学生・クリエイターが、直感的な興味を入口に「こだわり」をたどり、制作の発想のきっかけを得るための卒業研究プロトタイプです。

## ファイル
- `index.html`：画面構造
- `style.css`：デザインとスマートフォン対応
- `script.js`：探索、検索、詳細、関連リンク、保存・メモ
- `images/`：差し替え用の画像を置くフォルダ（必要に応じて作成）

## 画像の差し替え
1. リポジトリ内に `images` フォルダを作ります。
2. 画像を例として `images/sekka.jpg` のような名前で入れます。
3. `script.js` の `items` 配列で、該当対象の `image:''` を `image:'images/sekka.jpg'` に変更します。
4. 画像を設定しない場合は、これまでの抽象的なCSSグラフィックが表示されます。
5. 画像が見つからない場合も、画像要素は非表示になり、背景のグラフィックが残ります。

画像は、利用条件・著作権・クレジット表記を確認してから公開してください。作品写真を使用する場合は、作品名・作者・所蔵先・撮影者など必要な情報も整理してください。

## 内容を編集する
`script.js` 内の `interests` がホームの感覚的な入口、`items` が探索対象です。各アイテムの `links` は `[対象id, 関係を説明する文章]` の配列です。リンク先のidが実在する対象のidと一致していることを確認してください。

## GitHub Pagesで公開する
1. このフォルダ内の `index.html`、`style.css`、`script.js`、`README.md` をリポジトリの最上位へアップロードします。
2. GitHubで `Settings → Pages` を開きます。
3. Source を `Deploy from a branch`、Branch を `main`、フォルダを `/(root)` にして保存します。
4. 公開処理後、Pages設定に表示されるURLを開きます。

## 研究内容の注意
初期データは画面と操作を検証するためのサンプルです。人物・作品の情報、こだわりの解釈、歴史的な関係は、公開前に文献・展覧会図録・所蔵館情報などで確認してください。本人が明言した考え方と、作品・活動から読み取った解釈は区別してください。出典欄の「未入力」を調査後に具体的な資料名・URL・ページ番号へ置き換えてください。

## 保存機能
保存した対象とメモはブラウザの `localStorage` に保存されます。端末間では同期されず、ブラウザデータ削除時に失われる可能性があります。
